# Memecoin-Simulation – Read-only Dashboard (SPIELGELD)

Nur-Lese-Ansicht einer **Papier-Trading-Simulation** mit Spielgeld auf echten Solana-Live-Kursen
(Datenquellen: DexScreener, GeckoTerminal, RugCheck). Keine echten Trades, kein Wallet, keine Anlageberatung.
Die Daten kommen etwa jede Minute aus einem Gist, den die Simulation aktualisiert.
